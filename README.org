#+TITLE: Flint

An experimental compiled systems langauge, implemented in modern C++.

* Goals

- Clear, minimal syntax inspired by Go.
- Compile-time memory safety through ownership and borrowing.
- Low-level control through explicit unsafe operations.
- Predictable performance with minimal runtime overhead.

These are design goals, not implemented features.

* Proposed syntax

#+begin_src flint
fn main() {
	var count = 42
}
#+end_src

* Status

Early development. The first milestone 	is token design and a lexer.

* Implementation

- Zig 0.17 (=src/*.zig=), ported from the C++20 reference (=src/*.hpp=).
- Backend: textual LLVM IR, compiled with =clang=.

#+begin_src sh
zig build                         # zig-out/bin/flint
zig build run -- examples/calls.fl
zig build test                    # unit tests + every examples/*.fl
#+end_src

=tests/expected/*.txt= holds the exact error output of the C++ version;
the example runner checks the Zig compiler against it byte for byte.
